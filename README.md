# Leading Intelligence
Advisory services for leaders and engineers adopting agentic software development.

## What We Do

Leading Intelligence helps engineering leaders and executives navigate the transition to agentic software development — the shift from writing code to directing AI agents that write code.

# Assessments
We offer free, open source readiness assessments for:

* Engineering leaders
* Technology executives
* Security leaders

These are designed to help you understand where your team stands today and what to focus on next.
